# cafShare

Лёгкий менеджер APK в стиле Material You: отправка и приём приложений, сохранение в Downloads.

## Что умеет

- Список установленных приложений с иконками, версией и размером
- Отправка APK через системное «Поделиться»
- Сохранение APK в `Downloads/cafShare`
- Приём APK: открытие файла, «Поделиться» из другого приложения, выбор через SAF
- Установка полученного APK с проверкой разрешения
- Поиск, вкладки «Приложения» / «APK-файлы», Material You на Android 12+

## Оптимизация

- Без Compose и лишних библиотек: AppCompat + RecyclerView + Material
- `minSdk 24` — запускается на Android 7.0 и старее «картошке»
- Одна Activity, фоновые задачи на одном Executor
- Release-сборка с R8 и shrinkResources

## Сборка

```bash
./gradlew assembleDebug
```

Или через GitHub Actions: пуш в `main` собирает APK и кладёт в артефакты.

Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

## Установка

Скачайте APK, разрешите установку из этого источника и установите. Для установки принятых APK приложению нужно разрешение «Установка неизвестных приложений».
